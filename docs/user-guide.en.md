# FrameNote

FrameNote is a Windows x64 video review desk. Open a video, capture a note at a displayed frame or across a time range, and hand off the video and editable notes in a single file. The included REAPER action recreates point notes as project markers and ranges as regions.

**Run the development build**

Install the .NET 8 Desktop Runtime, Microsoft Edge WebView2 Runtime and x64 Visual C++ Redistributable. Building from source requires a compatible .NET SDK. Put FFmpeg and FFprobe on PATH, or put their executables in a `tools` folder beside FrameNote.exe. The Windows x64 build includes [LibVLC](https://docs.videolan.me/libvlcsharp/) 3.0.24 via LibVLCSharp.WPF 3.10.2; the VLC desktop application is not required. Keep the adjacent libvlc folder with the application.

Select **打开文件** on the welcome screen or drop a video there to start frame review. H.264/AAC MP4 and other compatible files open directly. When FrameNote or FrameNote Player needs to generate a preview for review, a centered progress bar shows the percentage. Select **取消加载** below the bar to cancel. If you select several videos, use the playlist to switch between them. Choose **VLC 播放** to play the original, or open files with **FrameNote Player** from Explorer.

In VLC, choose **进入批注** to review at the current position. For media requiring conversion, FFmpeg creates a temporary H.264/AAC preview of the first video and audio streams. Preparation can be cancelled; it can take time and disk space on long videos. The desk checks preview frame timestamps against the original before enabling notes. The preview uses 8-bit video, does not include subtitle tracks, and is removed on normal exit. Export and REAPER use original media; REAPER still needs to support its codec. Opening a review package goes directly to review, preparing the preview if needed. Windows file associations are unchanged.

From the repository root, run `pwsh -File scripts/build.ps1` and start `artifacts/app/FrameNote.exe`. The executable also accepts a video or a .framenote file as its first argument. Keep its adjacent DLLs and folders together. No cloud service or account is needed.

**Settings and shortcuts**

Open **文件 → 设置** in FrameNote or Player and select an action. Click its existing binding to replace it, or choose **添加快捷键** to add an alternative. Press the keys for a keyboard shortcut. For a mouse gesture, select the modifiers and mouse button. Use the trash icon to remove a binding. Choose **确定** to return to the list, then **保存** to apply your changes to both applications. The reset icon beside a group restores that group's defaults. **恢复默认** restores all groups. **打开默认应用设置** opens Windows file associations.

On the review canvas, hold Ctrl and drag with the left mouse button to draw a rectangle, or with the right button to draw an arrow. Ctrl-click with the middle button to place a text box and start typing. Each gesture creates a separate Mark at the current playhead. A plain right-click opens the annotation menu.

**Image viewing**

Open an image from the file dialog, by dragging it in, or from Windows Open with. Scroll over the image to zoom around the pointer; drag with the left button when enlarged. The arrows on the two sides of the image, or the Left/Right keys, open the previous/next image in the same folder in natural filename order and restore the fit-to-window view. GIF, APNG and animated WebP retain their animation; TIFF opens its first page. Press Ctrl+V on an empty desk to view a clipboard image directly. In image mode the volume control is hidden. Choose 添加批注 (M) to add text, arrows or rectangles; choose a color in the details panel. These notes stay attached to the image while zooming and panning. Use **复制批注图** to paste a flattened image into a chat, or **另存为 PNG…** to save it. Both keep the complete source image, numbered badges, drawings and attached pictures, independent of zoom and pan. Copy appends a panel below the image with the number, color and full text of each note; if there are no notes, no panel is added. Save as PNG keeps the original dimensions without the panel. Transparency is preserved; animated images export their first frame. Edits stay available when you switch between images in the same window. Export a .framenote before closing to keep the original image and editable notes, including for clipboard images. Image packages use format version 2 and carry the original media; notes on animated images apply to the whole animation. With a video open, the same shortcut still adds an image annotation. Setup registers FrameNote as a candidate image viewer; choose it in Windows Default apps for the extensions you want.

**Review and exchange**

Use **复制当前帧** to copy the current video frame as a Windows clipboard image, or **另存当前帧…** to save the same pixels to a PNG. Arrows, boxes, reference pictures and numbered badges stay on the frame. Below it, each active point or range has its color, number, timestamp or interval, and full text. Frames without annotations keep their original dimensions. Paste a copied frame into chat with Ctrl+V.

Web links in note text are recognized when displayed, including in existing review packages. Clicking a link opens the system default browser without seeking the video. URL detection uses the bundled [Linkify.js](https://github.com/nfrasser/linkifyjs) 4.3.2 ([MIT license](../src/FrameNote/ui/vendor/linkifyjs/LICENSE)).

Each review numbers point and range notes together in creation order. Numbers stay fixed when editing, deleting or undoing, and appear in the note list, editor, clickable timeline labels and REAPER marker/region names. Older reviews without numbers are assigned them in timeline order on load. Choose a color in the note editor to match its on-screen shape and number with the sidebar badge and timeline label. Hover a shape or badge to highlight its note without changing the selection. Point labels center on their timestamp; range labels span the marked interval.

1. Opening a video starts playback. Scrubbing keeps the current playing/paused state; selecting a timeline or sidebar note pauses on its start frame. The volume slider above the desk controls both playback engines and restores the last level (initially 100%). Ctrl+wheel does not resize the interface. Use Space for playback, Left/Right to step by presentation timestamp, or scrub the time slider. Zoom the timeline for short events.
2. Locate the frame, then select a drawing tool and draw directly on the canvas. Each completed drawing creates its own Mark at that playhead position. Choose **图片批注** or paste a picture with Ctrl+V to create a picture Mark. To add a reference picture to an existing note, right-click its shape or badge and choose **添加附图**. PNG, JPEG, BMP and WebP imports are stored as PNG with a maximum long edge of 2048 pixels. M adds a text Mark. I and O on different frames create a Region.
3. Notes and timeline edits stay in the current window. Closing it discards these edits and cleans up temporary attachments. Reopening the original media starts a new review. Choose **导出审阅包** before closing to keep an editable, portable copy. A version 1 package is ZIP with `review.json` and `media/source.<extension>`, plus deduplicated `images/<hash>.png` entries for picture notes; media is stored without transcoding. Time values are integer microseconds relative to media start, and drawing coordinates are normalized to the video image. A package is a snapshot: export again after editing.
4. Click the REAPER logo with the up arrow. On first use, choose a directory for the Lua action (normally REAPER's Scripts folder). Subsequent clicks compare the installed script with the bundled copy and update it in place when needed. No action-list registration is needed for sending. With one REAPER instance open, select a track, position the edit cursor in the target project tab, then click the logo again. Alternatively, drag the button onto a track in the REAPER arrange view. The item starts at the release position without moving the edit cursor; pressing Escape cancels. Dragging uses the bundled receiver, including before the first click-to-install. A plain video is inserted without notes; an opened .framenote sends its current committed point and range notes as markers and regions with their FrameNote colors. With no selected track, FrameNote creates a track; with several selected, it uses the first. Temporary recordings and package media are copied into **FrameNote Media** beside the saved project, or under **%LOCALAPPDATA%/FrameNote/REAPER** for an unsaved project. Ordinary videos keep their original paths. A single undo removes the insertion and its markers; copied files remain on disk. Duplicate review packages are rejected. The [Fontaudio REAPER glyph](https://github.com/fefanto/fontaudio) is used under its [MIT license](../src/FrameNote/ui/reaper-LICENSE.txt).

**Capture**

For a region recording, choose **显示器内框选区域**, select the monitor, then click **框选区域** and drag on the desktop. The settings show the selected dimensions; **重新框选** lets you replace the selection, and Esc during a new drag keeps the previous one. Click **录制视频** or **录制 GIF** when ready. A click-through border marks the outside of the region until capture stops.

Use the left capture panel to choose a display, window or drag a rectangle within a display. Select a frame rate and quality preset; use **混音器 → 添加输出设备** to add multiple Windows outputs and optionally select one microphone. Set each horizontal fader (−60 to 0 dB) and mute before recording; only the recorded stereo mix changes. For VBMatrix, select the Matrix Out return bus that carries your mix under **系统输出**. When the Windows default is a Matrix In device, FrameNote initially selects the matching numbered Matrix Out if available. Matrix routing is user-defined: choose another return if your mix goes there. The microphone slot stays available for a separate input. Before recording, meters show the selected endpoint's Windows peak; while recording, they show the captured PCM signal with the strip gain and mute applied. A DAW's exclusive ASIO output may not appear on the Windows loopback endpoint. Use the app's stop button or Ctrl+Alt+F9 (if available system-wide). Choosing **录制视频** starts recording immediately. Stopping opens the temporary clip for review without a save dialog. Its notes stay in the current session; switching videos or closing the app discards this review. To keep it, choose **导出审阅包** and save a self-contained .framenote file. The independent **录制 GIF** button starts immediately and asks where to save only after stopping (30-second limit). GIF output contains no audio.

**Engineering and verification**

The desktop host is WPF. A local WebView2 renders video and the review UI; frame callbacks provide displayed timestamps, and FFprobe supplies the ordered source timestamps for stepping. ScreenRecorderLib records video. NAudio captures timestamped WASAPI system/mic packets; on stop FFmpeg aligns each audio stream, mixes and encodes AAC, and copies the original video stream. Allow temporary disk space for PCM and the final MP4. FFmpeg also encodes GIFs. REAPER's Lua action delegates package validation and media extraction to the same FrameNote executable used by the desk.

Their geometry and colors are defined in [scripts/make_icons.py](../scripts/make_icons.py); run it on Windows with Python and Pillow to regenerate the two ICOs and the preview. Normal builds use the checked-in icons. The application icon is embedded in the executable; the document icon ships as `Assets/FrameNote_File.ico` for the Windows Setup file association.







## Annotation tools and rendered video

New notes appear in the sidebar and timeline immediately, including empty notes. Empty notes are included when exporting a review package. Use the card's delete button to remove one. Drag either edge of a Mark on the timeline to turn it into a Region. You can also press I to set the in point and O to finish the Region (default shortcuts). In note details, enter a positive duration in seconds to convert a Mark into a Region. A duration of zero restores a Mark; durations cannot extend beyond the video.

Each note supports one drawing plus optional reference pictures. Drag an existing drawing or picture on the canvas to move it. Select a line, arrow or ruler and drag either endpoint to change its length or direction. An angle has three movable points. Drag a corner to resize a rectangle, text box or magnifier. Pictures keep their original proportions. Double-click a text box to edit its text in the details panel. Escape cancels a drag, and Ctrl+Z undoes a completed drag. Right-click the canvas to choose a new annotation type. Right-click an existing annotation to edit its details, change its color, duplicate it at the same time and position, or delete it. In details, edit the start time or duration in seconds. Dragging either edge of a non-voice timeline label adjusts the interval.

- **Line**: drag between two endpoints.
- **Angle**: click the first endpoint, the vertex, then the second endpoint. The smaller angle is shown in degrees.
- **Distance ruler**: drag between two points. Distance is measured in source-image pixels, not screen pixels or physical units.
- **Magnifier**: drag a rectangle. It displays a live 2x enlargement of the rectangle's central half, including during video playback.
- **Text box**: drag a rectangle and type in the note's text field. Text wraps inside the rectangle; enlarge the box for longer text. The full note remains available in the sidebar and exported video footer.

Voice annotations use the same audio mix as screen recordings. Select system outputs and an optional microphone in the left audio mixer, set gain and mute per source, and enable at least one source. Click the microphone in the annotation toolbar, or choose **语音批注** from the canvas menu. Recording starts a separate annotation at the playhead while the video plays at 1×. Click the stop icon in the same toolbar position to keep the recording, or press Escape to discard it. Recording also finishes at the end of the video or after ten minutes. The resulting Region follows the recording duration and includes a mono AAC attachment. Use **试听语音** to audition it and **移除语音** to remove the attachment. Normal video playback mixes active voice notes with the source audio.

**导出 Excel** exports the current video review to a new folder. Open **批注清单.xlsx** to see the note numbers, types, start and end times, text and embedded previews. **打开 PNG** opens the displayed frame at a Mark (up to 1920 × 1080). **播放 GIF** opens a looping, silent 12 fps animation of the full Region (up to 800 × 800). Both use the edited timeline and show that row’s drawing and reference pictures. Move or send the workbook together with its **media** folder. Repeating the export creates a separate folder.

**导出 MP4** renders drawings and reference pictures into the video, adds a dark text area below the picture, and mixes in voice annotations. A Mark appears at its timestamp for one second or until the end of the video. A Region appears from its start up to its end. The footer keeps a fixed height throughout the export and includes all simultaneous note text. The original media is preserved. The export uses H.264 CRF 20, the medium preset, AAC 192 kb/s audio, and fast-start metadata. The source picture fits within 1920x1080 without upscaling; the footer adds height. Export uses the source average frame rate up to 120 fps, so variable-frame-rate sources become constant-frame-rate output. Exports with live magnifiers render the magnified source on every frame. Progress and cancellation are available; cancelled or failed exports do not replace the destination. Already compressed sources may produce a larger output, especially when annotations add visual detail. Keep a .framenote copy when editable annotations are needed. Older FrameNote versions do not support the new drawing types or voice attachments.
