# 跨框架桌面软件样式规范

以 ZipMerge 0.1.20 为视觉参照，适用于 Qt、WPF、WebView2 和 Win32 桌面应用。目标是在同一台机器、同一主题和缩放比例下，让同类控件具有一致的外观和状态，同时保留 Windows 原生窗口行为。

颜色、基础尺寸和控件造型取自 ZipMerge。为使不同框架的实现可以对照验收，本规范另外约定：**尺寸按最终可见外框计算；界面字体和等宽字体随应用分发并固定版本；主窗口、子窗口和弹出层共同验收。**

## 1. 主题与颜色

默认跟随系统，允许用户手动选择深色或浅色。一个应用内只保留一处主题状态；切换主题时，已经打开的设置、帮助、更新记录和弹出层也应同步。各框架使用下表中的颜色用途，不在业务页面里另选近似色。

| 用途 | 深色 | 浅色 |
|---|---|---|
| 窗口底色 | `#141416` | `#E5E9EE` |
| 菜单栏、工具栏、状态栏 | `#1B1B1D` | `#EDF0F4` |
| 内容面板 | `#202022` | `#F4F6F9` |
| 按钮、下拉框、弹出菜单底色 | `#252628` | `#F8FAFC` |
| 波形画布、滑杆轨道底色 | `#18181A` | `#EEF2F6` |
| 普通控件悬停 / 按下 | `#2A2B2E` / `#18181A` | `#EBEFF4` / `#E2E7ED` |
| 分隔线 / 控件边框 | `#34373C` / `#44484E` | `#AEB7C2` / `#929EAB` |
| 主文字 / 次文字 / 禁用文字 | `#ECEEF1` / `#A5AAB2` / `#6E747C` | `#1C232A` / `#495766` / `#7B8794` |
| 滚动条滑块 | `#4E5258` | `#495766`，30% 不透明度 |
| 危险动作 | `#E04F4F` | `#C23D43` |

**强调色**默认跟随系统，读取失败时回退为 `#0078D4`。沿用 ZipMerge 的处理：若强调色与控件底色的对比度低于 3:1，深色主题下向白色调整，浅色主题下向黑色调整，直到足以辨认。主要按钮、键盘焦点、滑杆填充使用调整后的强调色。实心强调色上的文字按对比度选黑或白。菜单和列表的选中背景使用强调色叠加：深色模式 18%、浅色模式 14%，文字保留主文字色。

## 2. 尺寸与缩放

以下数值均为 **96 DPI 下的逻辑像素**。控件高度指最终可见外框，包含内边距和边框；不要把同一个数值直接当作各框架的内容高度。字号放大时允许控件增高，文字不得被裁切。

| 项目 | 基准值 |
|---|---|
| 按钮、下拉框等标准控件高度 | 常规 32；紧凑 28 |
| 边框 / 分隔线 | 1 |
| 控件圆角 / 面板及弹出菜单圆角 | 5 / 6 |
| 常用间距 | 4、8、12、16、24 |

## 3. 控件

### 标题栏

保留 Windows 原生标题栏、系统字体、窗口按钮和拖动行为。主窗口、设置、帮助和更新记录等独立窗口都要向系统声明应用当前的明暗模式。标题栏不规定精确色值：系统材质和窗口激活状态可以造成色差。标题栏下方由应用绘制的菜单栏、工具栏使用规定的栏区底色。

### 菜单

菜单栏使用栏区底色。弹出菜单使用控件底色、1 边框、6 圆角，四周内边距 4。菜单项上下内边距 6，选中底色圆角 4。左侧预留图标或勾选列；有图标和无图标项的文字起点一致。快捷键靠右，子菜单箭头位于最右。禁用项使用禁用文字色，分组使用 1 宽的分隔线。主菜单、右键菜单和按钮弹出菜单遵循同一套规则。

### 下拉框

与同一行的按钮等高，使用控件底色、1 边框、5 圆角。文字左留 8；右侧预留 24，放置 16 × 16 的统一下箭头图标。悬停或键盘聚焦时使用强调色边框。收起的框面和展开的列表都必须定义主题：列表使用控件底色、1 边框、5 圆角、内边距 4，选中项使用主题选中色。

### 滚动条

横向与纵向使用同一造型。占位厚度 12，轨道透明，滑块四周留 2，可见厚度约 8；滑块圆角 3，最短长度基准 32，两端不设箭头。正文阅读区、列表、弹出列表、设置页和更新记录不单独更换滚动条皮肤。

### 按钮

普通按钮使用控件底色、1 边框、5 圆角，文字左右各留 14。悬停使用悬停底色和强调色边框，按下使用按下底色。禁用时使用禁用文字色并弱化边框。键盘焦点必须独立可见，不能只实现鼠标悬停。

| 类型 | 用途与外观 |
|---|---|
| 普通 | 常规操作，如“关闭”“取消”；使用普通控件底色。 |
| 主要 | 当前最重要的操作；使用实心强调色，按背景选择文字色。 |
| 低强调 | 次要操作或工具栏操作；默认背景透明，悬停时显示背景。 |
| 危险 | 删除等破坏性操作；使用危险色，不把普通关闭操作做成危险按钮。 |

### 滑杆、进度条与电平表

音量、缩放、可拖动的播放进度使用同一滑杆：轨道厚 4，圆形手柄直径 14，已调部分和手柄使用纯色强调色。可点击区域覆盖整行控件高度，不要求用户精准点中 4 像素的轨道。

只读进度条使用画布底色和强调色填充，圆角 3，**不显示手柄**。Peak/RMS 电平表用于读数，按音频表头需要定义刻度、警戒色和峰值保持，不套用滑杆皮肤。

## 4. 界面字体与数字

应用内容设两种文字角色：**界面字体**和**等宽读数**。按信息用途分配角色，不因为文本里出现数字就更换字体。Windows 原生标题栏使用系统字体；应用内图标统一使用 Fluent System Icons 正式资产，不用 Unicode 字符代替箭头、勾选框或按钮图标。

| 内容 | 字体与规则 | 示例 |
|---|---|---|
| 界面文字、静态数值 | 随应用提供固定版本的 **Noto Sans SC**。辅助文字 12，菜单、按钮和正文 14，小标题 17，标题 20。正文常规字重，标题使用统一的较重字重。 | 打开文件、版本 1.5.92、48 kHz、24 bit、文件名、批注编号 #1 |
| 实时变化或需逐位比较的读数 | 随应用提供固定版本的 **Cascadia Mono**。数字使用等宽字体，旁边的中文标签仍使用界面字体。 | 00:00.667、实时 −18.4 dB、播放中的帧号、拖动音量时的 100% |
| 波形和时间线刻度 | 使用 **Noto Sans SC 12**、常规字重。按时间位置对齐，不随旁边播放时钟更换字体。 | 0 s、0.2 s、0.4 s |

例如，说明文字里的“100%”用界面字体，跟随滑杆变化的“100%”用等宽字体。ZipMerge 当前会按本机可用字体依次查找 Cascadia Mono、Cascadia Code、Consolas、Courier New；**本规范将固定版本的 Cascadia Mono 作为正常交付字体**，系统回退只用于异常情况。

## 5. 跨框架实现与验收

维护一份带版本的规范、颜色与尺寸表、字体文件、图标资产和标准控件对照图。Qt 将这些值映射为 QSS（Qt 样式表），WPF 映射为共享样式与控件模板，WebView2 映射为 CSS，Win32 映射为系统主题接口或控件绘制规则。混合应用中的各层使用同一主题状态和同一组数值。

| 验收场景 | 检查内容 |
|---|---|
| 更新记录窗口 | 同屏比较标题栏、标题、版本下拉框、长正文、滚动条和关闭按钮。展开版本列表，确认主题连续。 |
| 菜单 | 打开含图标、无图标、禁用项、快捷键和子菜单的菜单，检查文字列、快捷键列、选中背景及键盘焦点。 |
| 播放控件 | 将滑杆、时间码及带数字的普通标签并排比较。拖动滑杆，确认时间码宽度稳定，点击范围覆盖整行高度。 |
| 主题与缩放 | 在深色、浅色以及 100%、150% 缩放下对照；子窗口打开时切换主题。检查外框尺寸、文字基线、图标、焦点和裁切。 |

系统标题栏材质、非活动窗口色和字体抗锯齿允许存在细微差异。默认白色弹出层、遗漏主题的子窗口、相同角色使用不同字体、键盘焦点不可见，均视为不符合规范。
