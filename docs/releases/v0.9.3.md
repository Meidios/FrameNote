# FrameNote 0.9.3

- 视频批注工具栏右上角新增 GIF 导出。悬停后可以选择「复制GIF到粘贴板」或「将GIF另存为...」。动图按剪辑后的时间线输出，包含画面批注和批注文字。
- 「文件 → 设置」里的快捷键按操作分组。同一操作可以使用多组快捷键，鼠标手势可分别选择修饰键和鼠标键。支持清空绑定、冲突提示和按分组恢复默认，原有快捷键配置会继续生效。
- 修复点击时间标尺后按 S 无法分割片段、整行标尺出现蓝框的问题。自定义的分割快捷键也能在标尺获得焦点时使用。
- 图片查看器的绘图工具移到右栏顶部，批注列表在中间独立滚动，详情和图片导出按钮在底部。统一顶部操作图标的视觉大小，更新批注界面和 Player 的按钮悬浮高光与提示。

**English**

- Export an annotated GIF from the upper-right toolbar in the video editor. Hover over GIF to copy it to the clipboard or save it as a file. The animation uses the edited timeline and includes drawings and annotation text.
- Shortcuts in File → Settings are grouped by action. Assign multiple bindings to an action or choose modifiers and buttons for mouse gestures. Clear a binding, resolve conflicts or restore a group’s defaults. Existing shortcut configurations still work.
- Fixed the S shortcut failing to split clips and drawing a blue outline around the timeline ruler after clicking it. Custom split shortcuts also work while the ruler has focus.
- The image viewer now places drawing tools at the top of the sidebar, a separately scrolling annotation list in the middle, and details and image export at the bottom. Toolbar icons have consistent visual sizes. Updated button highlights and tooltips in the editor and Player.
