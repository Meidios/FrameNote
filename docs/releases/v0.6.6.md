# FrameNote 0.6.6

**中文**：修复启动主程序或打开审阅包时可能误报「OperationCanceled」的问题。现在只等待审阅页自己的导航结果。若安装目录中的页面未能加载，会在当前用户的临时目录中从程序内置资源恢复界面并重试一次，无需管理员权限。

**English**: Fixed a startup failure that could report “OperationCanceled” for an unrelated navigation when launching FrameNote or opening a review package. If the installed review page cannot load, FrameNote restores its bundled interface to the current user's temporary folder and retries once without elevation.
