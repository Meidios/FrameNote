# FrameNote 0.8.0

- 新增非破坏性多轨剪辑：视频、原声音频、录音批注和批注轨可分割、裁剪、删除、移动，原始素材保留在审阅包中。
- 默认联动所有轨道。选中片段后移动或删除时，同一时间区间内的其他轨道一起调整；跨越边界的片段和 Region 会先分割。关闭“联动所有轨道”可独立编辑选中片段。
- 删除保留空隙，不自动前移后续内容。拖动时吸附同轨相邻片段的头尾；按住 Alt 可暂时关闭吸附。片段两端可拖动裁剪，并在源素材范围内恢复。
- 播放头处按 S 分割；选中片段后按 Delete 删除。Ctrl+Z 撤销，Ctrl+Shift+Z 重做。Mark 无时长，移动或删除 Mark 本身不切除媒体。
- 剪辑后的时间线用于预览、同步语音录制、截图、VLC 播放、MP4 导出和发送 REAPER。视频空隙显示黑画面，声音空隙保持静音；语音仍与原声混合。
- 缩略图和原声波形按片段的源区间显示。剪辑结果与联动状态随草稿和审阅包保存。

剪辑后的审阅包使用新格式，需要 FrameNote 0.8.0 或更新版本；旧包仍可打开。当前编辑范围为已打开视频及其原声、语音附件和批注，同一视频或原声音轨不允许片段重叠，语音片段可叠加混音。裁剪不会删除源素材；最终 MP4 按输出帧率呈现边界。

首次导出、截图或切换 VLC 时，会先在临时目录合成剪辑后的媒体；后续操作复用相同剪辑结果。MP4 导出支持在合成期间取消。最终 MP4 仍使用 H.264 CRF 20 和 AAC，画面最高 1080p，并在下方显示批注文字；Mark 默认显示 3 秒。
