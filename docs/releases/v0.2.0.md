首次安装后可双击 .framenote 审阅包，直接看到视频和批注。普通视频的默认播放器不会改变。

新增「帮助」菜单：可以手动检查更新、关闭启动检查，或离线查看使用帮助和更新记录。更新前可查看目标版本的说明，下载可以取消；安装后首次运行才会提示升级成功。

支持用内置 VLC 播放原片，在需要时进入逐帧批注。可以添加点和区间、图形和图片，复制当前帧，再将审阅包发送到 REAPER。

**English**

Double-click a .framenote package after installation to see its video and annotations. Your default player for regular videos is preserved.

The Help menu adds manual update checks, a startup check preference, offline help, and release notes. Read the target release notes before updating or cancel a download. The upgrade confirmation appears on first launch after installation.

Play the original video in the built-in VLC player and switch to frame-by-frame review when needed. Add marks, regions, shapes and images, copy the current frame, and send the review package to REAPER.
