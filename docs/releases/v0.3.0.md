打开视频后会自动播放。拖动进度条保留当前播放状态；点击时间线或右侧列表里的点、区间批注，则暂停在批注起始帧。主窗口右上角的播放音量同时控制审阅和 VLC，初始为 100%，重开后记住上次的值。Ctrl＋滚轮不再缩放界面。

可以直接打开 PNG、JPEG、BMP、GIF、WebP、APNG、AVIF、ICO 和 TIFF 图片；TIFF 显示首页，GIF、APNG 和动态 WebP 可保留动画。空界面按 Ctrl＋V 会打开剪贴板图片，视频内按 Ctrl＋V 仍添加图片批注。

安装后可从 Windows「打开方式」或 FrameNote「帮助 → 默认应用设置」选择 FrameNote 打开图片。
