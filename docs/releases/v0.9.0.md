# FrameNote 0.9.0

- 欢迎页打开视频直接进入批注界面。可以从批注工具栏或画面右键菜单新建图形、图片或语音批注，在设置里自定义快捷键。
- 时间线上可以整体拖动 Region，关联语音同步移动。语音批注与录屏共用左侧混音器，录屏默认 60 fps。
- 可导出 Excel 批注清单及对应的 PNG、GIF，也可以用卡片右下角的图标复制单条批注的纯文本。
- 批注和剪辑仅在当前窗口保留，需要下次继续编辑时，请先导出审阅包。
- Windows x64 安装包改用共享的 FFmpeg 媒体库，并提高压缩级别。

**English**

- Videos opened from the welcome screen enter the annotation editor. Create shapes, images or voice annotations from the toolbar or canvas context menu. Customize shortcuts in Settings.
- Drag an entire region on the timeline to move its linked voice recording with it. Voice annotations and screen recording use the same mixer. Screen recording defaults to 60 fps.
- Export an Excel annotation list with PNG and GIF assets. Copy an annotation as plain text using the icon on its card.
- Edits and annotations last for the current window session. Export a review package to resume later.
- The Windows x64 installer shares FFmpeg libraries and uses stronger compression.
