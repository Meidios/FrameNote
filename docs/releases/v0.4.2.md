# FrameNote 0.4.2

中文

- Windows 标题栏、帮助菜单、更新记录、网页审阅区和内置 VLC 播放器现在跟随同一套深浅主题。切换系统主题时，已经打开的更新窗口也会同步。
- 按钮、下拉框、滚动条和音量／时间线滑杆采用统一外观。界面随包提供 Noto Sans SC；播放时间和实时音量使用 Cascadia Mono。
- 本版保留原有工作区布局、快捷键、批注颜色和审阅包格式。一次性交付可编辑批注请导出 .framenote；分享静态画面可直接复制批注图或保存 PNG。

English

- The Windows title bar, Help menu, release history, review desk and built-in VLC player now share one light/dark theme. Open release-history windows update when the Windows theme changes.
- Buttons, drop-downs, scrollbars, volume and timeline sliders share the same styling. Noto Sans SC ships with the app for interface text; Cascadia Mono is used for playback time and live volume.
- The workspace layout, shortcuts, annotation colors and review-package format are unchanged. Export a .framenote file for editable feedback, or copy an annotated image or save a PNG for a still.
