# FrameNote 0.4.4

中文：顶部的录制视频、录制 GIF、打开文件和导出审阅包，以及播放栏的六个操作改为图标按钮。悬停可查看中文说明；播放和录制按钮随状态切换为暂停或停止图标，快捷键保持不变。

English: The four file and capture actions and six playback toolbar actions now use icons. Hover for a description; playback and recording switch to pause and stop icons when active. Existing shortcuts are unchanged.
