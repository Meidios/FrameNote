# FrameNote 0.5.0

中文：在「录制设置 → 混音器 → 添加输出设备」中可连续选择多个系统输出，并按需选择一个麦克风。每路都有横向电平表、−60 至 0 dB 增益和静音。录制前的设置只影响成片中的立体声混音，不改变 Windows 播放音量。GIF 仍然无声。

English: Under Recording settings → Mixer, add any available Windows outputs and optionally select a microphone. Each horizontal strip has a peak meter, −60 to 0 dB gain and mute. Set the stereo mix before recording without changing Windows playback volume. GIFs remain silent.

自 0.4.2 以来，新增「文件」菜单，修复深色菜单栏白带，录制和播放工具栏改用图标。欢迎页现在用大号 **FRAMENOTE** 替代「视频审阅」。

Also new since 0.4.2: a File menu, a fix for the white band on the dark menu bar, icon buttons for recording and playback, and a single **FRAMENOTE** heading on the welcome screen.
