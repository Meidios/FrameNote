# FrameNote 0.6.7

**中文**：修复从资源管理器打开 `.framenote` 审阅包或 MP4 时，安装目录的审阅页响应缓慢可能导致窗口空白约 30 秒的问题（[#1](https://github.com/Meidios/FrameNote/issues/1)）。现在直接加载程序内置的审阅界面，启动时显示加载提示；录制设备在后台枚举，不会挡住界面显示。

**English**: Fixed a roughly 30-second blank window when opening a review package or MP4 from Explorer if the installed review page stalled ([#1](https://github.com/Meidios/FrameNote/issues/1)). FrameNote now opens its bundled review interface directly, shows a loading message during startup, and discovers recording devices off the UI thread.
