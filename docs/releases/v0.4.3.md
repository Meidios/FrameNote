# FrameNote 0.4.3

中文：调整主窗口原生控件的绘制方式，避免深色菜单和音量栏出现白带。新增「文件」菜单，可打开视频、图片、审阅包或退出。视频播放器仍使用原有渲染方式。

English: Changed how the main window draws its native controls to avoid a white strip across the dark menu and volume bar. The new File menu opens videos, images and review packages, or exits the application. Video rendering is unchanged.
