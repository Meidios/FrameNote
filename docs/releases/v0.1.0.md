试用版：支持打开视频、逐帧审阅、点与区间批注、导出审阅包和发送到 REAPER。录屏和 GIF 可从主界面开始，录屏停止后直接进入临时审阅。

**English**

The preview release opens videos for frame-by-frame review, supports point and region annotations, exports review packages, and sends them to REAPER. Start a screen recording or GIF from the main window. Stopping a video recording opens it for temporary review.
