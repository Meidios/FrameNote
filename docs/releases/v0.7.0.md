# FrameNote 0.7.0

**中文**

- 进点、出点改为图标，保留 I／O 快捷键。新建批注立即出现在列表和时间线，空白批注也可保存。
- 批注详情新增时长编辑：正数将 Mark 转为 Region，0 恢复 Mark。
- 新增带批注的 MP4 导出：画面保留图形和参考图，下方显示完整批注文字。Mark 默认显示 3 秒，Region 按区间显示；语音批注与原声混合，支持进度显示和取消。
- 新增语音批注：可选择本机输入设备，跟随视频录制，停止后生成 Region。支持试听、同步回放，并随审阅包保存。
- 新增线、三点角度、像素距离标尺、2× 实时放大镜和文字框，支持图片及视频导出。

MP4 使用 H.264 CRF 20 与 AAC，原画面最高 1920×1080，文字区另加高度；已高度压缩的原片不保证再次导出一定更小。单段语音上限 10 分钟。含新图形或语音附件的审阅包需要使用新版 FrameNote 打开。

**English**

- In/out controls now use icons and retain the I/O shortcuts. New annotations appear immediately in the list and timeline, including empty notes.
- Edit a note's duration to convert a Mark to a Region; zero restores a Mark.
- Export annotated MP4 video with drawings and reference images over the picture, full note text below it, and voice annotations mixed with the original audio. Marks display for three seconds; Regions follow their intervals. Export includes progress and cancellation.
- Record voice annotations from a selected input device while the video plays. Recording creates a Region; audio supports audition, synchronized playback, and portable review packages.
- Added lines, three-point angles, source-pixel rulers, live 2x magnifiers, and text boxes for image and video review.

MP4 export uses H.264 CRF 20 and AAC, with the source picture fitting within 1920x1080 and additional height for annotation text. Already compressed inputs may not become smaller. Each voice recording is limited to ten minutes. Review packages with new drawings or voice attachments require an updated FrameNote version.
